# BatpodLabs

Personal site — developer portfolio + motovlog journey, with 3D scroll-driven animation as the visual signature.

## Stack

- React + TypeScript + Vite
- Tailwind CSS v4
- [Lenis](https://github.com/darkroomengineering/lenis) — smooth scroll
- [react-three-fiber](https://github.com/pmndrs/react-three-fiber) + [drei](https://github.com/pmndrs/drei) — Three.js in React, for [ThreeUI](https://threeui.com) components
- [Animate UI](https://animate-ui.com) — copy-paste animated React components (peer deps installed: `clsx`, `tailwind-merge`, `motion`, `class-variance-authority`; `cn()` helper at `src/lib/utils.ts`)

## Getting started

```bash
npm install
npm run dev
```

## Status
